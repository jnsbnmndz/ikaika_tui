# Commands (PowerShell-compatible)
- Interactive TUI: `python -m company_tui`
- List capabilities: `python -m company_tui list`
- Environment diagnostics: `python -m company_tui doctor`
- Tests: `python -m unittest discover`
- Editable install: `python -m pip install -e .`
- Refresh repository graph after code edits: `graphify update .`
